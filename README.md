# Agency Template Arsenal — Client Showroom & White-Label Studio (`tpl-00-agency-showcase-hub`)

Master Freelancer Client Showroom & Instant White-Label Personalizer deployed on Cloudflare Pages.

## Features
- **18 Stocked Vertical Templates across 5 Categories:** E-Commerce (5), Landing Pages (4), Creative Portfolios (3), Small ERP / POS (4), and Large Enterprise ERP (2).
- **4 Runnable Architecture Tracks per Template:**
  1. **Cloudflare Serverless Edge ($0/mo):** Cloudflare Pages + Workers (Hono) + D1 SQLite + R2.
  2. **WordPress / WooCommerce:** Blocksy Child Theme + Custom Operations/POS Plugin.
  3. **Shopify OS 2.0:** Dawn Liquid Sections + JSON Templates.
  4. **Self-Hosted Docker VPS:** Medusa.js, ERPNext, Odoo, Akaunting, Directus, Cal.com.
- **Dual-Persona Previewer:** Toggle between `Customer Storefront / App` and `Owner Admin / POS Command Center`.
- **Responsive Device Viewport Switcher:** Preview inside `1280px` Desktop, `768px` Tablet, `375px` Mobile, or Fullscreen frames.
- **Instant Client White-Label Magic Link Generator:** Re-skin any stocked template with `?brand=&tagline=&primary=&wa=&logo=` without rebuilding or exposing source repositories.
